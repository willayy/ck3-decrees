# Agent Guidelines & Paradox Scripting Resources

## Debug Setup
- Launch Crusader Kings III with `-debug_mode`.
- Open console (`~` or `) and execute `script_docs`.

## In-Engine Documentation (`script_docs`)
- Output log directory (macOS): `~/Documents/Paradox Interactive/Crusader Kings III/logs/`
- `effects.log` (all valid script effects)
- `triggers.log` (all conditional triggers)
- `event_scopes.log` and `event_targets.log` (scope definitions)
- `modifiers.log` (modifier list)
