# Contributing Guidelines

## Conventional Commits
All commits must follow the
[Conventional Commits](https://www.conventionalcommits.org/) specification.

## Versioning Scheme (`yyyymmdd-i`)
Releases and mod versions follow the date-based CalVer format `YYYYMMDD-i`.

### Version Format
`YYYYMMDD-i`

### Format Breakdown
- `YYYY`: Four-digit year of release (e.g., 2026).
- `MM`: Two-digit month of release (01–12).
- `DD`: Two-digit day of the month (01–31).
- `-i`: Incremental integer sequence for releases on that date, starting at 1.

### Examples
- `20261016-1` (first release on October 16, 2026)
- `20261016-2` (second release on October 16, 2026)
